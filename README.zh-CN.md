<h1 align="center">Milo</h1>

<hr />

Milo 是一个 AI Native 浏览器：一个把网页、上下文和自主 Agent 放进同一个工作空间的桌面浏览器。

过去，浏览器是互联网的入口。现在，Milo 要把浏览器升级为智能工作的操作系统。AI 不再只是页面旁边的聊天框，而是浏览器运行时的一部分：标签页是上下文，网页是工具，重复流程会沉淀为记忆，Agent 可以在用户可见、可控的浏览器环境里完成真实的网络任务。

## 宏大变化

第一代浏览器让人阅读网页，第二代浏览器让人搜索网页。AI 时代需要更大的跃迁：浏览器必须理解意图，操作软件，记住有价值的流程，并在关键节点让人保持控制。

Milo 正是为这个时代设计。它不是“传统浏览器 + 助手”，而是一种新的 Web 交互层：浏览、自动化、数据提取、翻译、学习、小组件、脚本和本地知识被设计成一个整体产品。

## Milo 代表什么

- **AI Native 架构**：Agent 是浏览器的一部分，而不是外挂侧边栏。
- **上下文工作空间**：会话、标签页、书签、下载、页面状态和学习行为都能成为结构化上下文。
- **面向任务的网页自动化**：Milo 可以导航、检查、提取、整理并执行多步骤浏览器任务。
- **本地学习能力**：把观察到的工作流沉淀为可复用策略，同时保留在本机。
- **可编程浏览器表面**：通过用户脚本、起始页小组件、协议组件和扩展兼容层扩展浏览器。
- **人类可控的自主性**：隐私模式、任务历史、中断恢复和模型 Provider 设置让用户始终掌握边界。

## 产品叙事

知识工作者已经生活在浏览器里。研究、运营、沟通、采购、分析、写作、后台系统、数据看板和内部工具都汇聚在浏览器中。但传统浏览器仍假设人类必须点击每个按钮、记住每条流程、复制每段信息，并手动把系统连接起来。

Milo 改变这个契约。

浏览器应该知道你在哪个页面，理解你要完成什么工作，能够打开标签页、比较信息源、提取结构化数据、草拟下一步、为重复流程生成小组件，并在下一次执行时变得更聪明。浏览器应该成为 Web 工作的伙伴，而不只是网页的容器。

这就是 Milo：面向“用意图编程 Web”的 AI Native 浏览器。

## 核心能力

- 面向长时间浏览器任务的 Agent 工作空间。
- 支持页面感知检查与自动化的 AI 侧边栏。
- 支持自定义小组件、内嵌内容、便签和停靠快捷方式的起始页。
- 通过 `milo://` 和 `widget://` 协议提供的本地小组件包。
- 用于增强普通网页的用户脚本编写能力。
- 从 Chromium 系浏览器导入浏览历史与书签。
- 面向精选 Chrome 扩展的扩展运行时兼容层。
- 可配置的 OpenAI 兼容 Provider，用于 Agent、翻译与学习。
- 本地学习资产：工作流指引、站点技能与行为摘要。
- 下载、Passkey、页面翻译、分屏视图、工作空间配置与浏览器级设置。

## 架构

Milo 基于 Electron、React、TypeScript 以及本地浏览器自动化运行时构建。

- `src/main`：Electron 主进程、浏览器运行时、协议、Agent、自动化、导入、服务与持久化。
- `src/renderer`：浏览器外壳、起始页、设置、Agent 工作空间、小组件、下载、书签、历史与学习等 React 界面。
- `docs`：小组件、扩展兼容与 Agent 数据提取的实现说明。
- `assets`：Milo 应用图标与品牌素材。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 打包桌面应用

```bash
npm run package:app
```

该命令在 macOS 上生成 `dist/mac-arm64/Milo.app`，并使用 ad-hoc 签名，避免因缺少开发证书或 `dmgBuilder` 下载导致本地打包失败。

如需创建发布安装包（例如已配置的 `dmg`），运行：

```bash
npm run package:release
```
